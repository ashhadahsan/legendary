The payments service (MOCKPAY_URL) /batch endpoint returns {"status":"accepted"} regardless, but only credits a record's amount toward /totals when `amount` is a JSON string. A raw JSON number is accepted but posted as 0.0 (an int is summed raw, not as currency). Fix in billing/client.py submit_batch: serialize amount with str(r["amount"]) in the payload. Verified: [{"amount":"19.99"},{"amount":"5.00"},{"amount":"0.01"}] -> totals.batch == 25.0.
