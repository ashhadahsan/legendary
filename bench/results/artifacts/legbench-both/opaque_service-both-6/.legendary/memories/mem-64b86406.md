The payments service at MOCKPAY_URL /batch returns {"status":"accepted"} but silently records amount as 0.0 when it is a JSON float. It only records amounts sent as JSON strings (e.g. "19.99") or integers. Fix in billing/client.py submit_batch: serialize each amount with str(r["amount"]). Discovered by probing /reset, /batch, /totals directly: float 19.99 -> total 0.0, string "19.99" -> 19.99, int 1999 -> 1999.0.
