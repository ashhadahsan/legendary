The payments service (MOCKPAY_URL) `/batch` and `/refund` endpoints return `{"status":"accepted"}` regardless, but only add a record's `amount` to server-side totals when `amount` is a JSON **string** (e.g. "19.99"). A JSON number (float) is silently recorded as 0.0; a JSON int is summed literally (no cents conversion). Fix in submit_batch: encode `amount` as `str(r["amount"])` in the payload. refunds.submit_refunds (still NotImplemented) must do the same or its totals won't reconcile. Verify with: GET /reset, POST /batch, GET /totals.
