The payments mock (MOCKPAY_URL, server at /Users/ashhad/legendary/bench/mockpay.py) has a deliberate quirk: any record whose `amount` is a JSON **float** is silently dropped from the total, while the response still returns 200 {"status": "accepted"}. Non-float amounts are summed via float(str(amount)), so `amount` MUST be serialized as a **string decimal** (e.g. "19.99") to be counted.

Symptom: submit_batch returned {"status":"accepted"} but /totals showed batch=0.0. Fix in billing/client.py: build payload with `"amount": str(r["amount"])`.

Applies equally to billing/refunds.py submit_refunds (still NotImplementedError) — it POSTs to /refund with the same {"records":[...]} shape and must also send amounts as strings.
